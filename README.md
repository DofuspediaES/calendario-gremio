# 🐰 WabbitAPP

Calendario privado para la organización de actividades del gremio de **Dofus**.

WabbitAPP permite a los miembros del gremio consultar, crear y participar en actividades, así como recibir recordatorios mediante Discord.

## ✨ Funciones

* 📅 Crear actividades del gremio.
* 👥 Gestionar participantes y cupos.
* 🎮 Vincular la cuenta de Discord.
* 📢 Publicar actividades automáticamente en Discord.
* 🔔 Enviar recordatorios por Discord antes de cada actividad.
* ⏰ Recordatorio automático 30 minutos antes.
* 🌎 Soporte para diferentes zonas horarias.
* 📜 Historial de actividades.
* 📱 Diseño compatible con PC y dispositivos móviles.
* ⚡ Instalación como PWA.

## 🛠️ Tecnologías

* HTML / CSS / JavaScript
* Supabase
* PostgreSQL
* Supabase Edge Functions
* Discord API
* PWA / Service Worker

## 🔒 Uso privado

WabbitAPP está diseñado exclusivamente para los **miembros del gremio**.

No es un calendario público ni una plataforma destinada al uso general.

## 🤖 Discord

La aplicación está integrada con Discord para facilitar la organización del gremio.

Las actividades creadas en WabbitAPP pueden publicarse automáticamente en el servidor de Discord y los participantes pueden recibir menciones cuando se aproxima la hora de inicio.

## 🔐 Configuración

Las credenciales y claves privadas utilizadas por Supabase y Discord se almacenan como variables de entorno y secretos.

**No deben incluirse claves privadas en el repositorio.**
